# Architecture

## Rendering

- Next.js App Router with `output: "export"`. `next build` writes static files
  to `out/`. No server runs in production.
- One route `/`, plus `404.html`, `robots.txt`, `sitemap.xml`, `icon.svg` and
  `opengraph-image.png`.
- Sections are server components. Client components are leaves:
  `Dock`, `SoundToggle`, `LocalClock`, `SmoothScroll`, `Reveal`, `CountUp`,
  `LensImage`, `ArchiveList`, `RagTerminal`, `CopyEmailButton`.

## Data flow

```
src/content/site.ts ──► section components ──► page.tsx ──► out/index.html
```

Content is typed (`Project`, `Role`, `Stat`, `ToolGroup`) and validated by
`src/content/site.test.ts`.

## Progressive enhancement

- Hero animations are pure CSS, so they start before hydration and don't hold
  back LCP.
- Reveal-on-scroll content is only hidden when the `.js` class is present (set by
  an inline script in `layout.tsx`). Without JS, everything is visible.
- `CountUp` and `RagTerminal` render their final state on the server. The
  client rewinds them before the first paint, then animates.
- Visitors who prefer reduced motion get no Lenis, no scroll-linked motion and
  instant transitions.

## Styling

Tailwind v4 is configured in CSS (`@theme` in `globals.css`). The custom CSS
that isn't a utility lives there too: keyframes, `condensed`/`stretchy`
utilities, the `--lens-r` `@property`, the duotone, reveal states, Lenis base
styles, film grain and the reduced-motion overrides.

## Fonts

`next/font/google` downloads Bricolage Grotesque (with `wdth` and `opsz` axes)
and Martian Mono at build time and serves them from the site. There are no
runtime requests to Google.

## Images

`next/image` with `unoptimized: true`, because the optimizer needs a server.
Screenshots are pre-optimized WebP files (`scripts/optimize-images.mjs`).
Images use `fill` inside fixed-aspect boxes, so layout never shifts.

## Audio

`AmbientEngine` (`lib/ambient.ts`) builds a Web Audio graph lazily on the first
click. `sound-store.ts` holds a single engine and exposes it to React through
`useSyncExternalStore`, so every toggle stays in sync.

## Metadata

`getSiteUrl()` returns `NEXT_PUBLIC_SITE_URL`, else
`VERCEL_PROJECT_PRODUCTION_URL`, else localhost. The social image is a static
PNG generated by `npm run og`.
